WebSpan

WebSpan connects web interfaces with Pythonista capabilities, enabling rich and interactive experiences powered by Python.

GitHub Repo Releases →

Easy to Use

Create a WebView and connect it to WebSpan:

                    
webview = ui.WebView()
span = PythonistaWebSpan(webview)

Register Python functions for your web app to call:

                    
span.register("getHttpbin", get_httpbin)
JavaScript Call 

const data = await webspan.call(
        "getHttpbin",
        "Hello from WebSpan! 👋"
    )
Python Function 

def get_httpbin(data):
    request = Request(
        HTTPBIN_URL + "?" + urlencode({"message": data}),
        headers=headers,
    )

    with urlopen(request, timeout=REQUEST_TIMEOUT) as response:
        return json.load(response)["args"]["message"]

Load and run your experience:

                    
span.load_html(html_path)
webview.present("fullscreen")
